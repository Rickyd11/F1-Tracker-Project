# F1-Tracker-Project
OpenF1 project to help track the f1 season

The goal is to make a mini F1 season tracker device. The device tracks the winners of the Last Race as well as the rest of the top five. The next feature is the Race track information, such as (circuit, country, and the current session key). The final feature is the driver's fastest lap. The current setup for the device is a 0.96 OLED Screen and an ESP32.
